<!-- Animation system architecture -->

The animation system uses three cooperating layers:

**Layer 1: CSS animation definition (in global.css)**
```css
@keyframes fadeRise {
  from { opacity: 0; transform: translateY(20px); }
  to   { opacity: 1; transform: translateY(0); }
}

/* Elements start invisible only after JS adds this class */
.will-animate {
  opacity: 0;
  transform: translateY(20px);
}

/* When Intersection Observer triggers, add this */
.will-animate.is-visible {
  animation: fadeRise 0.5s ease-out both;
}

/* Stagger delay utility classes */
.stagger-1 { animation-delay: 0.1s; }
.stagger-2 { animation-delay: 0.2s; }
.stagger-3 { animation-delay: 0.3s; }

/* Respect reduced-motion */
@media (prefers-reduced-motion: reduce) {
  .will-animate {
    opacity: 1;
    transform: none;
  }
  .will-animate.is-visible {
    animation: none;
  }
}
```

**Layer 2: HTML classes on target elements (per page — done in 05-03)**
Add `class="animate-on-scroll"` to elements that should animate. The JS will convert these to `will-animate` class, ensuring SSR/no-JS visitors always see content.

**Layer 3: JS Intersection Observer (one <script> block in BaseHead)**
```javascript
function initAnimations() {
  const prefersReduced = window.matchMedia('(prefers-reduced-motion: reduce)').matches;

  if (!prefersReduced) {
    document.querySelectorAll('.animate-on-scroll').forEach(el => {
      el.classList.add('will-animate');
      el.classList.remove('animate-on-scroll');
    });

    const observer = new IntersectionObserver((entries) => {
      entries.forEach(entry => {
        if (entry.isIntersecting) {
          entry.target.classList.add('is-visible');
          observer.unobserve(entry.target);
        }
      });
    }, { threshold: 0.1, rootMargin: '0px 0px -50px 0px' });

    document.querySelectorAll('.will-animate').forEach(el => observer.observe(el));
  }
}

// Run on initial page load and after View Transitions navigate
document.addEventListener('astro:page-load', initAnimations);
```

**Astro View Transitions:**
Astro 5.x supports the View Transitions API natively via:
```astro
---
import { ViewTransitions } from 'astro:transitions';
---
<!-- In <head> -->
<ViewTransitions />
```
This gives cross-page fade transitions with zero JS overhead. Add to BaseHead.astro.

**Known pitfall:** View Transitions can reset scroll position on mobile Safari. Test before marking complete.

**Known pitfall:** The animation script must re-run after View Transitions navigate. Use Astro's `astro:page-load` event instead of DOMContentLoaded:
```javascript
document.addEventListener('astro:page-load', () => { /* observer setup */ });
```
