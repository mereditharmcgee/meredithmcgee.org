**OG image design (1200x630px):**
Create as SVG in public/og-image.svg. SVG is the easiest to create programmatically and renders crisp at all sizes. Social platforms that require raster images will render the SVG.

If SVG does not render well on social platforms (some don't support SVG OG images), create a simple HTML file that can be screenshotted, or use a minimal approach with a solid color background and text.

**Alternative approach if SVG OG images are not supported:**
Create the OG image as a static PNG/JPG. Since we can't generate images at build time without extra libraries, create a minimal SVG and note that the user may want to screenshot and save as PNG for maximum compatibility.

**PRACTICAL RECOMMENDATION:** Create the file as `public/og-image.svg` with the design. If social platforms don't render SVG well, the user can convert to PNG later. The BaseHead image path just needs to point to the file.
