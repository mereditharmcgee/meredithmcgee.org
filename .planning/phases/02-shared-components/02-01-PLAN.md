The complete component:

```astro
---
import { XMLParser } from 'fast-xml-parser';
import { SUBSTACK_FEED_URL, SUBSTACK_URL } from '../consts';

interface Props {
  limit?: number;
}

interface SubstackPost {
  title: string;
  excerpt: string;
  url: string;
  date: Date;
}

const { limit = 3 } = Astro.props;

let posts: SubstackPost[] = [];

try {
  const res = await fetch(SUBSTACK_FEED_URL);
  if (!res.ok) {
    throw new Error(`RSS fetch failed: ${res.status}`);
  }
  const xml = await res.text();

  const parser = new XMLParser({
    ignoreAttributes: false,
    cdataPropName: '__cdata',
  });

  const result = parser.parse(xml);
  const rawItems = result?.rss?.channel?.item;

  // Normalize: fast-xml-parser returns an object (not array) when there's only 1 item
  const items = Array.isArray(rawItems) ? rawItems : rawItems ? [rawItems] : [];

  posts = items.slice(0, limit).map((item: any) => {
    // Handle CDATA-wrapped fields: value may be string or { __cdata: string }
    const getField = (val: any): string => {
      if (typeof val === 'string') return val;
      if (val && typeof val.__cdata === 'string') return val.__cdata;
      return '';
    };

    return {
      title: getField(item.title),
      excerpt: getField(item.description),
      url: typeof item.link === 'string' ? item.link : '',
      date: new Date(item.pubDate),
    };
  });
} catch (e) {
  // Build continues; posts stays empty, fallback renders below
  console.warn('[SubstackFeed] Failed to fetch RSS feed:', e instanceof Error ? e.message : e);
}
---

{posts.length > 0 ? (
  <div class="substack-feed">
    {posts.map((post) => (
      <article class="substack-post">
        <time datetime={post.date.toISOString()}>
          {post.date.toLocaleDateString('en-US', {
            year: 'numeric',
            month: 'long',
            day: 'numeric',

          <a href={post.url} target="_blank" rel="noopener noreferrer">
            {post.title}
          </a>
```

KEY IMPLEMENTATION NOTES:

1. **Build-time fetch only**: The `fetch()` is in the frontmatter block (`---`), which runs at build time in Astro SSG. There is no `<script>` tag with fetch. This avoids CORS issues entirely.

2. **CDATA handling**: The `cdataPropName: '__cdata'` option tells fast-xml-parser to surface CDATA content. The `getField()` helper handles both plain string and `{ __cdata: string }` formats because fast-xml-parser behavior can vary depending on whether a field actually uses CDATA wrappers.

3. **Single-item normalization**: The `Array.isArray(rawItems)` check handles the edge case where the feed has only one item and fast-xml-parser returns an object instead of an array.

4. **Graceful fallback**: The try/catch wraps the entire fetch+parse pipeline. If anything fails, `posts` stays empty and the fallback "Read the latest on Substack" link renders instead. The build does NOT throw or fail.

5. **Date format**: Uses `month: 'long'` for "February 25, 2026" format per the decisions in 02-CONTEXT.md.

6. **Styling**: Uses the existing CSS custom property system. Colors match the site palette. The border-bottom divider between posts uses the established `rgba(212, 201, 142, ...)` pattern from the codebase.

7. **No `<script>` tag**: This component has no client-side JavaScript. Everything runs at build time.
