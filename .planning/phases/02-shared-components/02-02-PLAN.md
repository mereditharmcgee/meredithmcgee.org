DESIGN NOTES:
- **Category label**: uppercase, small, muted (opacity 0.6), above the title. Per CONTEXT: "plain uppercase text label above the title (e.g., RESEARCH)"
- **Title**: prominent heading in Playfair Display. If a link exists, the title itself is clickable. If no link, plain text.
- **Description**: body text below title in Source Sans 3.
- **Link presentation**: When a link exists, both the title and a separate "Read more" arrow link are clickable. This gives two clear affordances. The "Read more" link is subtle and uses arrow entity.
- **Card style**: Minimal flat with border-bottom divider. No box shadows, no background fill, no elevation. Matches the SubstackFeed post divider pattern.
- **Colors**: Uses CSS custom properties from the existing design system. Gold for titles/links, cream for body text, matching the dark-background sections of the site.
