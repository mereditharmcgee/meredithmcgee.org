**Tooltip script (add as `<script>` block in about.astro):**

```javascript
document.addEventListener('astro:page-load', () => {
  const tooltip = document.getElementById('footnote-tooltip');
  const tooltipText = tooltip?.querySelector('.footnote-text');
  if (!tooltip || !tooltipText) return;

  const triggers = document.querySelectorAll('.footnote-trigger');
  if (triggers.length === 0) return;

  triggers.forEach(trigger => {
    trigger.addEventListener('click', (e) => {
      e.stopPropagation();
      const aside = trigger.getAttribute('data-aside');
      if (!aside) return;

      tooltipText.textContent = aside;

      // Position near click with viewport clamping
      const TOOLTIP_WIDTH = 280;
      const x = Math.min(e.clientX + 10, window.innerWidth - TOOLTIP_WIDTH - 15);
      const y = Math.max(e.clientY - 80, 80);
      tooltip.style.left = `${x}px`;
      tooltip.style.top = `${y}px`;

      tooltip.classList.add('visible');
      tooltip.setAttribute('aria-hidden', 'false');
    });

    // Keyboard support
    trigger.addEventListener('keydown', (e) => {
      if (e.key === 'Enter' || e.key === ' ') {
        e.preventDefault();
        trigger.click();
      }
    });
  });

  // Dismiss on click anywhere else
  document.addEventListener('click', () => {
    tooltip.classList.remove('visible');
    tooltip.setAttribute('aria-hidden', 'true');
  });

  // Dismiss on Escape key
  document.addEventListener('keydown', (e) => {
    if (e.key === 'Escape') {
      tooltip.classList.remove('visible');
      tooltip.setAttribute('aria-hidden', 'true');
    }
  });
});
```

Claude should draft the actual message text during execution. Guidelines:

- Warm and understated. Not a tech boast ("built with Astro") or generic ("made with love")
- One line, short
- The example "made with care, coffee, and a black lab at my feet" is the exact right tone. Claude can use this verbatim or draft something equally personal.

**Footer CSS (add to Footer.astro `<style>`):**
```css
.footer-secret {
  color: rgba(45, 58, 30, 0.03);
  font-size: 0.65rem;
  margin-top: 0.5rem;
  cursor: default;
  transition: color 0.4s ease;
  user-select: none;
  text-align: center;
  letter-spacing: 0.02em;
}

.footer-secret:hover,
.footer-secret.revealed {
  color: rgba(236, 230, 208, 0.35);
}

@media (prefers-reduced-motion: reduce) {
  .footer-secret {
    transition: none;
  }
}
```

The color `rgba(45, 58, 30, 0.03)` is essentially `--color-dark` at 3% opacity — invisible against the `--color-dark` background. On hover (desktop) or tap (mobile), it becomes cream at 35% — muted but legible.

**Footer JS (add `<script>` block to Footer.astro):**

```javascript
document.addEventListener('astro:page-load', () => {
  const secret = document.querySelector('.footer-secret');
  if (!secret) return;

  // Mobile tap reveal (hover doesn't work on touch)
  secret.addEventListener('click', () => {
    secret.classList.toggle('revealed');
  });
});
```

This is minimal: `:hover` handles desktop, the click handler adds/removes `.revealed` for touch. No additional complexity needed.

**IMPORTANT: Do NOT use `aria-hidden="true"` on the footer message** — per RESEARCH.md, if a screen reader user discovers it, they should be able to read it. The near-invisible color is a visual trick only.
