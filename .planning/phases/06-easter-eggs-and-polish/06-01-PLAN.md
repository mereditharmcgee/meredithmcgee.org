<task type="auto">
  <name>Task 1: Create EmberClick.astro component with popup overlay and particle system</name>
  <files>src/components/EmberClick.astro</files>
  <action>
Create `src/components/EmberClick.astro` as a self-contained component with no props. This component injects the shared overlay elements and all interaction logic. It will be imported once per page that has Ember mentions.

**HTML structure (in the component template):**
- A single fixed-position overlay container `#ember-overlay` with `aria-hidden="true"` containing:
  - `.ember-popup` div (holds the photo `<img>` and optional `.ember-caption` paragraph)
- The overlay starts hidden (`display: none`). No visual output until triggered.

**Scoped CSS must include:**

1. `.ember-trigger` styles (these style the spans in the page files):
   - `border-bottom: 1.5px dotted var(--color-gold)` for the affordance hint
   - `cursor: pointer`
   - `touch-action: manipulation` (eliminates 300ms tap delay on iOS)
   - `color: inherit` (don't change the text color)
   - On hover: `border-bottom-color: var(--color-cream)` transition

2. `#ember-overlay` styles:
   - `position: fixed; inset: 0; z-index: 1001; pointer-events: none; display: none`
   - When `.active`: `display: block`

3. `.ember-popup` styles:
   - `position: fixed; width: 180px; height: 180px; border-radius: 12px; overflow: hidden; pointer-events: auto`
   - `box-shadow: 0 10px 30px rgba(0,0,0,0.4)`
   - `border: 2px solid var(--color-gold)`
   - `z-index: 1002`
   - `img` inside: `width: 100%; height: 100%; object-fit: cover`

4. `.ember-caption` styles:
   - `position: absolute; bottom: 0; left: 0; right: 0`
   - `background: rgba(45, 58, 30, 0.85)` (dark overlay for readability)
   - `color: var(--color-gold); font-family: 'Playfair Display', Georgia, serif; font-size: 0.8rem; font-style: italic; padding: 0.4rem 0.6rem; text-align: center`

5. `.ember-particle` styles:
   - `position: fixed; width: 6px; height: 6px; border-radius: 50%; background: var(--color-gold); pointer-events: none; z-index: 1002`
   - `animation: particleBurst 0.8s ease-out forwards`

6. `@keyframes particleBurst`:
   - `0%`: `opacity: 1; transform: translate(0, 0) scale(1)`
   - `100%`: `opacity: 0; transform: translate(var(--dx), var(--dy)) scale(0.3)`

7. `@keyframes floatDismiss`:
   - `0%`: `opacity: 1; transform: translateY(0)`
   - `100%`: `opacity: 0; transform: translateY(-40px)`

8. `.ember-popup.dismissing`: `animation: floatDismiss 0.6s ease-in forwards`

9. `@media (prefers-reduced-motion: reduce)`:
   - `.ember-particle { animation: none; opacity: 0; }` (or skip creating them entirely in JS)
   - `.ember-popup.dismissing { animation: none; display: none; }`

**Script block (`<script>`):**

Use `document.addEventListener('astro:page-load', initEmberClick)` pattern.

`initEmberClick()` function:
1. Check `window.matchMedia('(prefers-reduced-motion: reduce)').matches` and store in `prefersReduced`.
2. Set `let emberClickCount = 0`.
3. Query `document.querySelectorAll('.ember-trigger')`. If none found, return early.
4. For each trigger, add `click` event listener:
   a. Increment `emberClickCount`.
   b. Determine `isSilly = emberClickCount >= 3`.
   c. Call `showEmberPopup(e.clientX, e.clientY, isSilly)`.

`showEmberPopup(x, y, isSilly)` function:
1. Get or create the overlay element. Set `display: block` (add `.active` class).
2. Set the popup image `src`:
   - Normal: `/ember.jpg`
   - Silly: `/ember-silly.jpg`
3. Position the popup near the click point with viewport clamping:
   ```javascript
   const POPUP_SIZE = 180;
   const popupX = Math.min(x + 15, window.innerWidth - POPUP_SIZE - 15);
   const popupY = Math.max(y - POPUP_SIZE - 15, 80); // 80px = header clearance
   ```
4. If `isSilly`, show the caption element with rotating text:
   ```javascript
   const captions = ['she says hi', 'good girl', 'best dog'];
   captionEl.textContent = captions[(emberClickCount - 3) % captions.length];
   ```
   Otherwise, hide caption.
5. If NOT `prefersReduced`, create 6-8 particles at the click point:
   - Each particle: `document.createElement('span')`, add class `ember-particle`
   - Set `style.left` and `style.top` to click coordinates
   - Set CSS custom properties `--dx` and `--dy` to random values:
     - `--dx`: `${Math.random() * 100 - 50}px` (spread left/right)
     - `--dy`: `${Math.random() * -80 - 20}px` (biased upward)
   - Append to `document.body`
   - Listen for `animationend` to remove the element (or `setTimeout(800)` as fallback)
6. Auto-dismiss: `setTimeout` at 2 seconds triggers dismissal.

`dismissPopup()` function:
1. If `prefersReduced`: immediately hide overlay (`display: none`), return.
2. Add `.dismissing` class to `.ember-popup`.
3. On `animationend` (or `setTimeout(600)` fallback): remove `.active` from overlay, remove `.dismissing` from popup.

**Particle cleanup:** Before creating new particles, remove any existing `.ember-particle` elements if count exceeds 30 (fast-click protection from RESEARCH.md Pitfall 2).

**Photo placeholders:** During development, the images `/ember.jpg` and `/ember-silly.jpg` won't exist yet. The component should still work — the popup appears with a broken image icon or empty space, which is acceptable for a placeholder. Add an HTML comment in the component noting: "Replace /ember.jpg and /ember-silly.jpg in public/ with real Ember photos before launch."

**IMPORTANT: Use `:global()` modifier** for `.ember-trigger` styles since those elements live in page files, not inside this component. Astro's scoped styles won't reach them otherwise. The overlay, popup, particle, and keyframe styles can be scoped since those elements are created by/within this component's script.

Actually, a cleaner approach: put the `.ember-trigger` styles in a `<style is:global>` block (separate from the scoped styles), or use `:global(.ember-trigger)` within the scoped `<style>`. The latter is preferred — keeps one style block.
