# Technology Stack

**Analysis Date:** 2025-02-28

## Languages

**Primary:**
- TypeScript 5.x - Used for components, layouts, and configuration files
- Astro (template language) - Used for page routes, layouts, and components in `src/pages/`, `src/layouts/`, `src/components/`

**Secondary:**
- CSS 3 - Global styles defined in `src/styles/global.css`, scoped component styles in `.astro` files
- HTML 5 - Generated by Astro pages and components

## Runtime

**Environment:**
- Node.js 20 (configured in `.github/workflows/deploy.yml`)

**Package Manager:**
- npm
- Lockfile: `package-lock.json` (present, lockfileVersion 3)

## Frameworks

**Core:**
- Astro 5.16.8 - Static site generator and framework for building the portfolio website
  - Configuration: `astro.config.mjs`
  - Entry point: `src/pages/` (file-based routing)

**Content Management:**
- Astro Content Collections - Schema-based content organization
  - Configuration: `src/content.config.ts`
  - Collections: `blog` (markdown with metadata), `portfolio` (markdown with extended metadata)

**Integrations:**
- @astrojs/mdx 4.3.13 - MDX support for content pages
- @astrojs/sitemap 3.6.1 - Automatic sitemap generation
- @astrojs/rss 4.0.14 - RSS feed generation

**Build/Dev:**
- TypeScript strict mode - Type checking via `tsconfig.json`
- Astro CLI - Development server and build commands via npm scripts

## Key Dependencies

**Critical:**
- astro 5.16.8 - Core framework for SSG and routing

**Content Processing:**
- @astrojs/mdx 4.3.13 - Markdown + JSX compilation
- @astrojs/markdown-remark 6.3.10 (transitive) - Markdown parsing and rendering
- rehype-stringify 10.0.1 (transitive) - HTML output from markdown
- remark-gfm 4.0.1 (transitive) - GitHub-flavored markdown support

**Image Processing:**
- sharp 0.34.3 - Image optimization and transformation
- @astrojs/image (implicit via Astro integration) - Image component optimization

**SEO & Discovery:**
- @astrojs/sitemap 3.6.1 - Sitemap XML generation at build time
- @astrojs/rss 4.0.14 - RSS feed generation for blog

**Other Transitive:**
- shiki 3.19.0 - Syntax highlighting in markdown code blocks
- js-yaml 4.1.1 - YAML frontmatter parsing
- github-slugger 2.0.0 - URL-safe slug generation

## Configuration Files

**Entry Points:**
- `astro.config.mjs` - Main Astro configuration with integrations and site URL
- `tsconfig.json` - TypeScript configuration extending Astro's strict preset
- `src/content.config.ts` - Content collection schemas

**Build Output:**
- `dist/` - Generated static site (production build output)

**Styling:**
- `src/styles/global.css` - Global CSS variables, typography, layout utilities, responsive breakpoints

## Platform Requirements

**Development:**
- Node.js 20 or compatible
- npm package manager
- Code editor (VS Code recommended, has `.vscode/` config)

**Production:**
- Static hosting (currently GitHub Pages via Actions workflow)
- Node.js build environment (CI runs `npm ci` and `npm run build`)

## Build & Deployment

**Build Commands:**
```bash
npm run dev      # Start dev server at localhost:4321
npm run build    # Build to ./dist/ for production
npm run preview  # Preview production build locally
npm run astro    # Run astro CLI commands
```

**CI/CD:**
- GitHub Actions workflow: `.github/workflows/deploy.yml`
- Trigger: Push to `main` branch or manual `workflow_dispatch`
- Environment: ubuntu-latest with Node 20
- Cache: npm cache enabled
- Deployment: Automatic to GitHub Pages via `actions/deploy-pages@v4`
